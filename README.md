# Petal & Stem

A responsive flower shop landing page built with HTML, CSS, and vanilla JavaScript. No build step or dependencies required.

## Run locally

```sh
cd /workspace/landing-page
python3 -m http.server 3000 --bind 0.0.0.0
```

Bouquet and occasion buttons open an accessible inquiry dialog with size selection and a prefilled email inquiry. The shop, prices, and `hello@petalandstem.example` address are demo content. Replace the email address in `index.html` and `script.js` before launch. Online payment and order fulfillment are not connected.

Typography uses Google Fonts with local serif and sans-serif fallbacks.
